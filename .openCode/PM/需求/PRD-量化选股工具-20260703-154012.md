# PRD：量化选股工具 MVP

## 1. 介绍/概览

本项目从零开始建设一个面向个人研究使用的本地 Web 量化选股工具。工具第一版支持 A 股全市场和美股主流股票，重点提供技术指标筛选、结果表格查看、个股详情、自选股管理和筛选条件模板复用。

本项目当前没有业务代码和工程结构，仅存在 `.openCode` 记录与设计文档。因此后续实施需要先创建项目骨架，再按后端、前端、验证记录逐步落地。

## 2. 目标

- 创建 FastAPI 后端与 Vue3/Vite 前端的本地 Web 应用骨架。
- 使用文件存储保存股票池、行情缓存、自选股、筛选模板和日志。
- 支持基于日线数据的技术指标筛选，第一版至少支持均线、MACD、RSI。
- 支持 A 股全市场股票池结构与美股主流股票池结构。
- 支持结果表格查看、排序、搜索、自选股标记和个股详情。
- 支持自选股分组管理和筛选条件模板 CRUD。
- 支持少量个股分钟走势查看，分钟数据不参与第一版批量筛选。

## 4. 功能需求

- FR-1：系统必须提供本地 FastAPI 后端服务。
- FR-2：系统必须提供 Vue3/Vite 前端页面。
- FR-3：系统必须通过文件存储保存股票池、自选股、筛选模板、行情缓存和日志。
- FR-4：系统必须支持查询 A 股和美股市场列表。
- FR-5：系统必须支持查询 A 股股票池和美股主流股票池。
- FR-6：系统必须支持基于日线数据执行技术指标筛选。
- FR-7：系统必须至少支持 MA、MACD、RSI 三类技术指标。
- FR-8：系统必须支持筛选结果表格展示、搜索、排序、命中原因和自选状态。
- FR-9：系统必须支持自选股分组、添加和删除。
- FR-10：系统必须支持筛选模板的保存、读取、更新和删除。
- FR-11：系统必须支持个股详情，包括日线指标和少量分钟走势。
- FR-12：系统必须对数据源失败、缓存缺失、指标计算失败、文件读写失败和空结果提供明确提示。

## 5. 非目标（范围外）

- 不做策略级回测。
- 不做自动交易或半自动交易。
- 不做实时行情盯盘。
- 不做多人权限和云同步。
- 不要求美股全市场覆盖。
- 不要求 CSV/Excel 导出。
- 不做自由表达式策略编辑器。
- 不要求第一版接入稳定付费数据源。

## 6. 设计考虑

- 前端以本地浏览器使用为主，优先保证清晰、可操作和状态反馈明确。
- 技术指标条件采用结构化表单，不允许第一版输入自由表达式。
- 前端不直接访问本地文件，所有读写都通过后端 API 完成。
- 筛选主页面是核心入口，模板管理入口放在筛选页中，避免第一版页面过多。

## 7. 技术考虑

- 当前项目为空项目，没有可复用业务代码。
- 后端建议使用 Python、FastAPI、Pydantic、pandas、pytest。
- 前端建议使用 Vue3、Vite、TypeScript。
- 数据源第一版可以使用样例数据和可替换数据源接口，保证离线可验证；后续再增强免费公开数据源接入稳定性。
- 行情缓存第一版使用 CSV，用户配置使用 JSON。
- 由于当前目录不是 Git 仓库，自动提交可能被阻塞；实施阶段需记录该风险。
